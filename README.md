Food Ordering System (Mini Project in C++)
This is a simple Food Ordering System built using C++ and the principles of Object-Oriented Programming (OOP).
It demonstrates the use of classes, inheritance, constructors, polymorphism, and file handling. 🚀

✨ Features
🔑 User Registration & Login – Secure login system with credentials stored in users.txt.

📋 Menu Display – Multiple food items available: Burger, Pizza, Pasta, Sandwich, Fries.

🛒 Order System – Place orders with quantity validation.

💰 Bill Calculation – Automatic total cost calculation.

👨‍💼 Delivery Management – Deliveryman details handled using Inheritance & Polymorphism.

🛠️ Tech Stack
Language: C++

Concepts Used: OOP (Classes, Inheritance, Polymorphism, Constructors)

File Handling: User data stored in text files

Project Structure:

Food-Ordering-System/

│── main.cpp          # Main source code
│── users.txt         # Stores user credentials
│── README.md         # Project documentation
